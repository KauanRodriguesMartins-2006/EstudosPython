# Consultor API

Projeto final do **Módulo 3** dos meus estudos de Python.

Uma aplicação CLI desenvolvida em Python para consultar e analisar dados da API [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

## Funcionalidades

* Consultar dados de usuários
* Consultar posts de um usuário
* Consultar um post específico
* Analisar posts de um usuário
* Exibir estatísticas gerais

## Tecnologias

* Python 3.13
* Requests
* UV
* JSONPlaceholder

## Como executar

```bash
uv venv
uv add requests
uv run ProjetoM3.py
```

## Objetivo

Praticar consumo de APIs, requisições HTTP, tratamento de erros, funções e processamento de dados em Python.
